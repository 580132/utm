# UTM Manager (MT5)

一套面向 **手动交易** 的 MetaTrader 5 下单 / 交易管理工具，按照
[Uber Trade Manager (UTM)](https://www.mql5.com/zh/market/product/93171) 官方文档
（[UTM Manager Guide](https://www.mql5.com/en/blogs/post/751613) 及其子章节）所列功能独立实现。

> 界面与提示信息全部为中文。本项目是**独立实现**，不包含、不反编译原商业产品的任何代码；UI 与参数命名按公开文档重建。
> 当前版本：**1.30**。面板标题右侧显示 `v1.30`，鼠标悬停可看编译时间；EA 启动日志也会打印 `[UTM] 版本 1.30（编译 YYYY.MM.DD HH:MM）`。

> 与原作者、MQL5 官方无任何关联。

## 3. 安装与更新

仓库地址：<https://github.com/580132/utm>

### 方式 A：一行命令安装（推荐）

```powershell
irm https://raw.githubusercontent.com/580132/utm/main/tools/install.ps1 -OutFile "$env:TEMP\utm-install.ps1"
& "$env:TEMP\utm-install.ps1"
```

脚本会从 GitHub 下载最新 Release 的源码，自动定位 MetaTrader 5 数据目录
（`%APPDATA%\MetaQuotes\Terminal\<hash>\MQL5`），复制 `Include\UTM` 与
`Experts\UTM Manager`，再调用 `MetaEditor64.exe` 编译并输出错误。

### 方式 B：克隆后本地安装（开发用）

```powershell
git clone https://github.com/580132/utm.git
cd utm
pwsh -ExecutionPolicy Bypass -File .\tools\install.ps1
```

本地存在 `MQL5\` 源码时，脚本直接复制当前工作区，便于改完代码立即编译。

### 更新到最新版

```powershell
irm https://raw.githubusercontent.com/580132/utm/main/tools/update.ps1 -OutFile "$env:TEMP\utm-update.ps1"
& "$env:TEMP\utm-update.ps1"
```

`update.ps1` 会读取已安装的 `UTM_Defines.mqh` 中的版本号，与 GitHub 最新 Release
比较；只有发现新版本才下载、覆盖安装并重新编译。加 `-Force` 可强制重装当前版本。

### 常用参数

```powershell
# 指定数据目录 / 编辑器
.\tools\install.ps1 -TerminalData "C:\Users\me\AppData\Roaming\MetaQuotes\Terminal\XXXX\MQL5" `
                   -MetaEditor   "C:\Program Files\MetaTrader 5\MetaEditor64.exe"

# 安装指定版本，或只复制不编译
.\tools\install.ps1 -Version v1.30
.\tools\install.ps1 -NoCompile

# 连同自测 EA 一起安装（不用于实盘）
.\tools\install.ps1 -IncludeTests

# 强制重装 / 只检查不安装
.\tools\update.ps1 -Force
.\tools\update.ps1 -CheckOnly
```

### 方式 C：手动安装

1. MT5 → `文件` → `打开数据文件夹`；
2. 把 `MQL5\Include\UTM` 复制到 `<数据目录>\MQL5\Include\`；
3. 把 `MQL5\Experts\UTM Manager` 复制到 `<数据目录>\MQL5\Experts\`；
4. 在 MetaEditor 中打开 `UTM_Manager.mq5`，按 `F7` 编译；
5. 回到 MT5，在“导航器 → 智能交易系统”里找到 **UTM Manager**。

2. 右键图表 → 取消勾选 **交易级别 / Trade Levels**
   （否则会和本 EA 画的线重叠，拖错对象）；
3. 图表属性中开启 **图表位移 / Chart Shift**，并把三角形拉到合适位置；

## 5. 下单与快捷键

### 5.1 快速市价单

面板 `BUY` / `SELL`：按当前 **止损设置** 自动计算手数并立即市价成交。

### 5.2 计划下单（执行模式）

按 `ESC`（或点 `EXEC`）进入执行模式。图表 **左下角状态条** 会显示
当前是否在执行模式、方向与订单类型，例如：

```
执行中   买入   市价   |   移动止损线，点击左键下单
止损 20.0 点      手数 0.10      风险 20.00
```

**市价模式（默认）**

1. 进入执行模式后只出现 **止损线**，它 **跟随鼠标** 移动；
2. 状态条实时显示该止损对应的点数、手数与风险金额；
2. 状态条与止损线旁的 **点数 / 手数 / 风险** 随现价实时变化（市价单按点击时的现价成交）；
3. **点击鼠标左键** → 立即以市价发送订单（止损 = 点击位置）。

> **方向自动翻转**：市价模式下若把止损线拖到当前价**上方**，会自动切换成
> **卖出**计划，止损在入场价上方、止盈线全部镜像到下方；再拖回下方则切回**买入**。
> 挂单模式同样适用（止损相对入场价判断）。左下角状态条会立即显示新的方向。
**挂单模式（LIMIT / STOP）**

1. 按 `Backspace`（或 `L` / `P` / 面板 `EXEC` 循环）切换到挂单模式；
2. 此时 **只出现入场线**（没有止损线、没有止盈线），入场线跟随鼠标；
3. **第一次左键点击** → 固定入场价；此时才出现止损线与止盈预览线；
4. **第二次左键点击** → 确认止损位置并发送挂单。

> **绿色点线** 是止盈预览线，来自面板 `TAKE PROFIT` 的 RR / 百分比设置，
> 线上标注如 `TP1 1.00R 50%`。未启用（百分比为 0）的止盈级别不会显示。
> 挂单在“确定入场”之前不显示止损/止盈，避免误判。
> **默认执行模式**：面板「持仓管理」里的 `默认模式：市价 / 限价 / 突破`，或 EA 参数 `InpDefaultOrderMode`，决定按 ESC / 点「执行」进入执行模式时先用哪种订单类型；
> 进入后仍可用 `Backspace` 临时切换。选限价/突破时，进入后会直接停在「先点入场线」这一步。

> 任何时刻都可以直接拖动入场线 / 止损线 / 止盈线做微调，
> 拖动后该线不再跟随鼠标，点击一次继续下一步。

**退出**：再次按 `ESC`。发送成功后自动退出执行模式（避免误点重复下单）。

> **面板按钮**：「执行」进入执行模式后变成「退出」（等同 ESC）。**面板上不设发送按钮**：
> 执行模式里入场/止损线跟着鼠标走，鼠标移到面板的途中线会被带偏，点按钮下单等于用被带偏的价格。
> 下单请用**图表左键**（线就在鼠标处，点哪用哪）或按 `Enter`。
> `保本 / 全平 / 撤挂` 三个按钮始终可用（快捷键则只在执行模式内生效）。

## 6. 点差处理

面板 `SPREAD` 循环切换 4 种模式：

### `Off`
所有价格按经纪商实际报价执行，止损/止盈正常发送。

### `Spread factor`（点差因子）
- 买单：入场价上移 `factor`，更接近“K 线价”；
- 卖单：止损价上移 `factor`，避免点差单独触发止损；
- `factor = 0` 时自动使用 EMA 平滑点差。

### `Ignore spread`（忽略点差）
按文档实现订单流：

| 方向 | 入场 | 止损 |
|---|---|---|
| BUY | EA 等 **Bid** 触价后市价买入（挂单为虚拟单） | 发送到经纪商（按 Bid 触发，与 K 线一致） |
| SELL | 直接发送到经纪商 | EA 监控 **Bid**，到价后市价平仓 |

- 买入挂单在忽略点差模式下是 **虚拟挂单**：EA 必须运行；
- 卖单止损由 EA 执行，实际平仓价会多一个点差（文档同样提示）；
- 可开启 **兜底止损**（2R 处的经纪商止损）防止断线 / 崩溃。

### `Ignore + invis`（隐形）
- 挂单、止损、止盈全部由 EA 内部执行，**不向经纪商发送任何挂单/止损**；
- 只有真正成交时的市价单会到达经纪商（这是成交本身必需）；
- 断线会导致虚拟单失效，务必使用稳定网络 / VPS。

> 所有模式都会把点差的 EMA 平滑值用于手数预估与异常点差过滤。

## 7. 交易管理公式

`MANAGEMENT → 公式框` 支持每行一条规则：`触发 RR : 动作 [参数]`，
多条用换行或 `;` 分隔。

| 动作 | 含义 | 示例 |
|---|---|---|
| `BE` | 把止损移到保本（可加 `BE+` 的 RR 偏移） | `1.0:BE` |
| `TS x` | 追踪止损，始终保留 `x` 倍 R 的距离 | `1.5:TS 1.0` |
| `CLOSE n` | 平掉 n% 初始手数（100 = 全平） | `3.0:CLOSE 50` |

示例：

```
0.5:BE
1.5:TS 1.0
3.0:CLOSE 50
```

含义：浮盈 0.5R 保本 → 1.5R 开始 1R 距离追踪 → 3R 平掉一半。

> 触发值按 **原始入场价** 计算（可由参数 `InpFormulaOrigEntry` 改为实际成交价）。
> 这是原版“公式语言”的简化实现，命令集不完全相同。

### 7.1 多级止盈：本地分批 / 服务器分批

| 模式 | 行为 |
|---|---|
| `服务器TP = 关` | 只有 EA 在**每个 tick** 检查价格并分批平仓；MT5 关掉后所有 TP 失效，只剩止损 |
| `服务器TP = 拆仓`（默认） | **挂单**按止盈比例拆成 2~4 张订单，**每张挂自己的止盈价**，由服务器执行，MT5 关掉也有效；市价单不拆（见下） |

- 只有**对冲账户**能持有同品种多个仓位；净额账户请把此项关掉。
- 每份必须 ≥ 最小手数：手数不够拆时（例如 0.02 手拆 3 份）自动退回「整仓挂**末级止盈**」。
- **市价单不拆仓**：市价成交有延迟/滑点，多张单的入场价会不一致，所以市价单保持一个仓位，并在服务器挂**末级止盈**兜底，TP1/TP2 仍由 EA 分批。
- **挂单**（限价 / 突破）拆成多张挂单，各自带自己的止盈；成交后就是多个独立仓位（注释相同 `UTM-<id>`）。
- 止盈比例合计 < 100%（留尾仓）时不挂兜底止盈，避免整仓被服务器提前平掉。
- 拆仓后账户里会看到 2~4 个仓位（注释都是 `UTM-<id>`），面板仍按一笔显示；移动止损 / 保本 / 全平会一次处理整组。
- 按「每笔」收佣金的券商，拆仓后佣金会按笔数增加（按手数收的不受影响）。

## 8. 参数说明（主要项）

| 参数 | 说明 |
|---|---|
| `InpMagic` | 本管理器专属 magic，务必每个图表不同 |
| `InpTradeSymbol` | 自定义品种 / 秒图无法解析时手工指定 |
| `InpRiskMode / InpRiskValue` | 风险 % / 金额 / 固定手数 |
| `InpUseProfile / InpForceInputs` | 启动时读取已保存配置 / 忽略配置强制用 EA 参数 |
| `InpMaxLot` | 单笔手数硬上限（0 = 不限） |
| `InpEquityStop` | 净值低于此值 → 全平并停止开仓 |
| `InpAbnormalSpread` | 当前点差 > EMA × 该倍数时禁止开仓 |
| `InpBypassMaxLot` | 超过经纪商最大手数时自动拆单 |
| `InpSLSize / InpSLUnit` | 止损大小与单位（points / pips） |
| `InpSLMin / InpSLMax` | 止损保护上下限 |
| `InpLockRR` | 拖动挂单入场线时是否保持 RR |
| `InpTPxRR / InpTPxPct` | 分批止盈 RR 与平仓百分比（0 = 关闭该级） |
| `InpBEPlusRR` | BE 时额外锁定的 RR |
| `InpSpreadMode / InpSpreadFactor / InpEMASpread` | 点差处理 |
| `InpFailsafeSL` | 虚拟止损时额外下 2R 经纪商止损 |
| `InpEntryColor / InpEntryStyle / InpEntryWidth` | 入场线颜色 / 线型 / 粗细 |
| `InpBuyColor / InpSellColor` | 多单 / 空单入场线颜色 |
| `InpSLColor / InpSLStyle / InpSLWidth` | 止损线颜色 / 线型 / 粗细 |
| `InpTPColor / InpTPStyle / InpTPWidth` | 止盈线颜色 / 线型 / 粗细 |
| `InpHudBackground` | 左下角状态条是否绘制背景框（关闭后只有文字） |
| `InpMemorySave` | 省内存：面板收起为**折叠态**（标题 / 余额 / 点差 / 买卖 / 执行按钮 / 状态行），图表上的文字和按钮不受影响；点 `+` 仍可临时展开 |
| `InpShowQuickTrade` | 面板是否显示「买入 / 卖出」快捷按钮（默认**不显示**，防误点） |
| `InpCommissionAuto / InpCommissionPerLot / InpCommissionInRisk` | 自动检测佣金 / 手动每手佣金 / 佣金是否计入风险（影响手数） |
| `InpServerSplitTP` | 多级止盈拆仓挂服务器（默认开）；关闭则由 EA 本地分批 |
| `InpDefaultOrderMode` | 默认执行模式（市价 / 限价 / 突破），按 ESC 进入执行模式时使用 |
| `InpUseProfile / InpProfile` | 启动时读取的设置档案 |

风险与手数计算使用 `SYMBOL_TRADE_TICK_VALUE_LOSS`，
佣金默认**自动检测**，两条来源，优先用品种规格：
1. **品种规格**：新版 MT5 提供 `SymbolInfoCommissions()`，直接读到券商标注的佣金规则（每手多少、只在入场收还是入场出场都收、按金额/点数/百分比、分档），
   换算成「每手往返」金额，**不用等成交**。
2. **成交记录**：规格里没写或读不到时，取最近 365 天该品种的实际 `DEAL_COMMISSION` ÷ 手数；
   已经有完整往返成交时，以实际扣费为准（会覆盖规格值）。

两条都拿不到时**按 0 计**（想手动指定就切到「手动」，手动模式下才用手填的值）。面板数字只读，鼠标悬停会显示来源（品种规格 / 成交记录 / 实际）。

点面板「自动 / 手动」可切换；切到手动时会以当前检测值为起点，方便微调。
打开 **佣金计入风险** 后，手数 = 风险金额 ÷ (止损亏损 + 每手佣金)，图表与状态条显示的风险金额也会包含佣金。

## 9. 设置保存

配置保存在 `Common\Files\UTM\`（所有终端实例共享）：

| 文件 | 内容 |
|---|---|
| `settings_<profile>.ini` | 全部参数（风险、止损、止盈、点差、线条样式、佣金…） |
| `settings_<profile>.ini.bak` | 上一次被覆盖前的备份 |
| `active_profile.txt` | 最近一次使用的配置名 |
| `state_<magic>_<symbol>.csv` | 持仓管理状态（分批止盈进度、保本标记、公式已执行步骤） |

**自动保存**：面板里改任何一项（点按钮、改输入框）会**立即写入文件**，
不需要再点「保存」；EA 卸载 / 图表关闭时也会再存一次。

**重启时用谁的值**：EA 会记住“上次保存时 EA 参数的指纹”（`inputSig`）。

| 情况 | 结果 |
|---|---|
| 只改过面板 | 重启后 **面板的值有效**（用配置文件） |
| 改过 EA 参数（属性窗口） | 重启后 **参数值有效**，旧配置自动备份为 `.bak` |
| 面板里改了配置名并保存 | 重启后仍然读**改名后**的那份（靠 `active_profile.txt`） |
| 想强制用当前参数 | 勾选 `忽略已保存配置（用当前 EA 参数覆盖）` |

> 回测 / 优化时 EA **不会**读写这些文件，避免污染实盘配置。

手动操作：面板 `保存` 写文件，`读取` 立即载入并刷新面板。

## 10. 自测

仓库内 `MQL5\Experts\UTM Tests\` 提供两个测试 EA（**不要用于实盘**）：

- `UTM_SelfTest.mq5`：在策略测试器中自动开一笔单，覆盖
  手数计算 / 分批止盈 / 保本 / 追踪止损 / 忽略点差虚拟挂单等路径；
- `UTM_UiTest.mq5`：构建整套面板并检查控件坐标、折叠、编辑、隐藏/显示。
- `MQL5\Scripts\UTM_CommProbe.mq5`：打印当前品种的佣金规则（`SymbolInfoCommissions` 原始内容），排查券商佣金用。

本机验证结果（EURUSD H1，2024 年数据）：

```
SELFTEST: QuickTrade(BUY) -> ok
SELFTEST: risk=20.00  tp1=1R  tp2=2R
SELFTEST: tpDone=1  curVol=0.05        ← TP1 平 50%
SELFTEST: position closed, balance=10011.34
UITEST: objects=92 edits=26 buttons=24 problems=0
```

运行方式：策略测试器 → 选择对应 EA → 模型“1 分钟 OHLC” → 关闭可视化。

## 11. 已知限制 / 与原版的差异

1. **净额账户（Netting）**：MT5 净额账户同一品种只有一个仓位，拆单、多笔独立管理无法按设计工作；
   请使用 **对冲（Hedging）** 账户。
2. **佣金**：默认自动读取「品种规格」里的佣金规则，读不到用成交记录推算；两者都没有按 0 计，不会偷偷用旧的手填值（手填值只在「手动」模式生效）。
3. **自适应风险公式语言**：未实现，风险值只能手工设置 / 快捷键减半。
4. **Trade Insights**：仅当日笔数、胜率、盈亏（同一计划拆出的多个仓位算**一笔**），无完整统计页。
5. **图表面板**：固定在左上角（不可拖动），展开高度 604px，图表太矮时自动折叠。
6. **回测**：非可视化回测下不绘图、不写状态文件（为性能）；功能逻辑仍会运行。
7. **秒图**：若无法自动解析品种，请在参数 `InpTradeSymbol` 手工指定。
8. **多实例**：同一品种不建议开多个实例（状态文件与 magic 会冲突）。

## 13. macOS / 高分屏（Retina）

macOS 上的 MT5 是通过 Wine 运行的，图表像素和字体常常只有 Windows 的一半大小，同时会带来几个平台差异。

### 13.1 界面太小

用 EA 参数里「基础」组的 `界面缩放（InpUiScale）`：

| 值 | 效果 |
|---|---|
| `0`（默认） | 自动：屏幕 DPI > 96 时按 `DPI/96` 放大 |
| `1.5` / `2.0` | 手动放大面板、图表文字、左下角状态条 |
| `1.0` | 关闭缩放 |

- 改了参数要重新加载 EA（或改完参数点确定）才生效。
- 面板放大后如果比图表还高，会自动按图表高度收敛（最小回到 1.0 倍），再放不下才折叠。
- macOS 一般先用 `2.0`；如果面板一直折叠，说明图表窗口太矮，把图表窗口拉大或改用 `1.5`。

### 13.2 无法下单

按下单流程点击后如果没成交，现在会**弹窗**并显示券商的返回码（例如 `(10027)`）。常见原因：

| 返回码 / 提示 | 处理 |
|---|---|
| `自动交易未开启` / `10027` | 点终端工具栏的「算法交易」按钮，变绿后再试 |
| `10030` | EA 会自动依次尝试 FOK / IOC / RETURN 三种成交方式，一般不再出现 |
| `10016` / `invalid stops` | 止损离现价太近，把止损线拉远一点 |
| `10015` / `invalid price` | 行情跳动太快，重新点一次即可 |

市价单现在用「按最新价成交」下单（不再锁死点击瞬间的价格），慢网络下也不会因为价格过期被拒。

### 13.3 切换周期时止损线 / 止盈线跑位

- 线本身是按**价格**画的，切换周期不会改价格；变的是图表的纵向比例。
- 之前切换周期时，终端会补发一次鼠标移动事件，执行模式里跟着鼠标的止损线会瞬间跳到新周期光标所在的价格。现在切换后 600 毫秒内忽略鼠标移动，且相同像素位置的重复事件也会被忽略，止损线保持不动。
- 切换周期后图上的文字标签会立即重画，不会和线条错位。
